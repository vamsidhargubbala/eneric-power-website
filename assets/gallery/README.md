# Website gallery images

This folder powers the **Gallery** carousel on the website.

To update an image without changing website code, replace one of these files with your own image while keeping the same filename:

- `gallery-01.jpg`
- `gallery-02.jpg`
- `gallery-03.jpg`
- `gallery-04.jpg`
- `gallery-05.jpg`

Use landscape images where possible, ideally at least 1600 pixels wide. Keep each image below 3 MB for faster loading.

To add a sixth or later image, upload it here and add one matching image line in the Gallery section of `index.html`.
